# WAiNK / CookieLabs — v1.12.5
Standalone WHIP resource inspired by GTA VI fictional vehicle gameplay. Uses the original WHIP Duo interface and the previously supplied V1.6 aiming bridge. All five transparent WebP inventory icons use original GTA VI-inspired artwork, not Rockstar extracts. Slim Jim uses the new explicit `html/img/items/waink_slimjim_vi.webp` path. Existing admin picture overrides may need resetting.

## Install
**Lock Kit:** no core config change is required. WAiNK passes its own ring difficulty using WHIP's inline `level` table API. The timer defaults to 18 seconds and can be changed in `/whip` > Settings > WAiNK > Skill games. Requires a WHIP build that supports inline ring levels.

1. Back up and replace **only** `whip_waink` if the V1.6 patched WHIP phone is still installed. Start after `whip_core` and `whip_phone` (`ensure whip_waink`). Requires OneSync.
2. If running an unmodified WHIP phone, use the separately supplied original WHIP Duo 1.1.0 with its WAiNK aim bridge. It is the same phone supplied with V1.6. Back up any custom apps or changes first. The stock phone does not expose `SetWainkAim`, which is needed for mouse aiming while the phone is open. No custom replacement NUI remains.
3. Open WAiNK on the normal handset. Start Scan enters first person and restores the previous camera and cursor afterwards. Old saved `NativePhone` settings are ignored. Unlisted models return identification only, with no sale/registration price until verified. Use `/whip` > Settings > WAiNK > Vehicle models > Approved add-on vehicle spawn names (comma separated; only add civilian road models you have verified; default `none`) or register the vehicle pack in WHIP's catalogue. Known restricted classes stay blocked. 
4. `/whip` > Settings > WAiNK: set and enable Vehicle dealer (existing Buyer location is retained), radius, blip, rates, ped model, heading and name. The dealer defaults enabled at 737.48, -1093.35, 22.17 with heading 82.04 and interior mode enabled. An explicitly saved 0,0,0 still prevents spawning. Existing saved enabled/disabled and location settings are retained. Use the Place or Here button to set the location, enable the dealer, and Apply. Use Ped height adjustment only if needed; enable Dealer inside MLO for an interior. The old registrar setting is no longer used. Set preview FPS 24, scan range 25 m, scan duration 1000 ms if older saved settings override defaults.
5. Stock or grant inventory items through WHIP: `waink_slimjim`, `waink_lockkit`, `waink_keycloner`, `waink_procloner`, `waink_signaltool`. Images are automatically registered from `html/img/items/`. These are fictional in-game items.

## V1.10 eligibility compatibility
The server now distinguishes an unknown population type (0) from explicit mission/permanent types (6/7), and verifies the entity AND plate against WHIP before any gameplay action. Unknown-population civilian catalogue cars and non-temp/non-secure WHIP session cars are accepted by default; the latter may include unmarked rentals or scripted cars, so disable the relevant settings if another resource uses them. Explicit rental, mission, protected, temporary, secured and owned flags are rejected. Unregistered scripted population 6/7 is not allowed by default; administrators can explicitly opt in under Vehicle eligibility only if appropriate for their server. Other unknown/protected origins still show estimated model-based information when the catalogue is known, but cannot access or transact. Estimates are fictional gameplay values. If a scan still shows protected, read the population/class/record line in the server console. Catalogue hash comparisons now handle signed/unsigned native hashes. Result scroll resets and the captured image is contained at a smaller size on unfolded screens. The original phone and inventory assets are unchanged.

## Gameplay
Scan moving or parked ambient NPC vehicles with known classes or approved models. Moving scans are read-only estimates. For actions, scan a parked, empty eligible street vehicle, use the required item and complete the fictional tracker challenge if applicable. Drive to the dealer (Market > Set waypoint), park within the configured radius, get out, and speak to Moses. Choose sale or registration and confirm the quoted price. Tools can be used from the scanned vehicle screen or from inventory after scanning. WHIP closes the handset for the native skill check; cloners and signal tool use WHIP phone games, and the Slim Jim/Lock Kit use the ring challenge. Failure grants no access. Sale pays the bank; registration charges the bank and claims the vehicle through WHIP. A registered vehicle is no longer eligible. Price and eligibility are calculated on the server, not from client-supplied values.

## Protection and limitations
Only eligible unowned session vehicles are actionable under the configured provenance policy. Persistent, player-owned, temporary, secure, player-occupied, restricted models and records bearing nonempty ownership fields are denied. Server rechecks ownership, provenance, vacant vehicle, location, character session, and tracker status immediately before deletion/claim; unknown ownership or invalid plate lookups are denied at transaction time. Custom ownership systems outside WHIP's records require their own explicit integration. Vehicle deletion/payment are separate WHIP operations, not an atomic transaction: if payment fails after deletion, staff reconciliation is required (server log). Registration refunds if eligibility changes or claim fails. Test with a non-production economy. Access profiles and history are session memory only; registration persistence is provided by WHIP. Previous WAiNK claims need a fresh eligible scan after restart. No real-world tracking or access methods implemented.

The preview directly samples the GTA viewport using FiveM's WebGL hook at 480×270, with capped FPS and optional single final local snapshot; no per-frame JPEG transport. Target acquisition is independent of preview health. No separate rear-camera render. This build retains five targeting rays, moving-vehicle tracking and first-person restoration. Only active aiming has per-frame client controls; the original phone owns focus and the app lifecycle. No measured resmon or FPS claims. Some FiveM builds may not expose the game-view hook. Custom DUI forks must retain the documented exports; not tested in runtime.

## V1.12 dealer lifecycle
Dealer refreshes now run in a deferred thread after settings changes and WHIP registration. Rapid changes are coalesced; failed native spawn or prompt creation is retried up to three times, with cleanup via the dealer tag. Console reports either an unset/disabled dealer, a failure reason, or successful NPC and network IDs. No default street location was chosen. Existing settings remain intact. No changes to the phone or transaction eligibility. Syntax checks only; native spawn not tested live.

## V1.12.1 dealer location
Default dealer placement is vector4(737.48, -1093.35, 22.17, 82.04), with interior mode enabled and zero height offset. Existing saved WHIP settings can override these defaults. In /whip > Settings > WAiNK, set the dealer Location and Enabled, then under Dealer character set Ped heading to 82.04 (or nearest supported value), Dealer inside MLO on and Ped height adjustment to 0. Apply. Park within the configured radius. If not visible, inspect server console for Dealer ready or Dealer attempt failure. No phone update needed. Location has not been tested in FiveM.

## V1.12.2 dealer tag fix
WHIP ReleaseTag permanently closes a tag. The old spawn function closed its own tag before creating the NPC, then reused it on every retry. Each spawn attempt now allocates a new tag, and only a previously allocated tag is released. Failed attempts are cleaned up. The new Use custom MLO loading gate setting defaults off for base-game interiors and deliberately ignores the old Buyer.interior setting. Dealer coordinates and all other saved settings are retained. At startup check the server console for Dealer ready or Dealer attempt failed; the blip alone does not prove a network NPC exists. No phone update required.

## V1.12.3 WHIP map legend
The old client-side GTA blip has been removed. WHIP's server ShowBlip/HideBlip API now manages one dealer marker, using the existing Buyer.name as its legend label (default Moses • Vehicle dealer). It is independent of the NPC tag and automatically removed on resource stop. Configure the label and visibility in Vehicle dealer, and sprite, colour, scale and minimap range in Dealer map blip. Defaults preserve the former icon and colour. Existing saved dealer placement and NPC lifecycle are unchanged. Requires a WHIP core exposing the documented ShowBlip/HideBlip exports. No phone update. Live map appearance not tested.

## V1.12.5 Lock Kit timing
The native server skill check now receives an inline ring level (`{ level = { pieces, parts, widest, narrowest, msPerPart } }`) instead of an undefined named preset. This preserves the 12-part ring and sets the default timer to 18 seconds (1500 ms per part). The Lock Kit timer is adjustable from 8–36 seconds. Other tools use their existing difficulty and games. No phone or core changes are needed for this update if the existing aiming bridge is installed and the core supports inline levels. An old `waink_lockkit` core preset is no longer used. Live testing required.
